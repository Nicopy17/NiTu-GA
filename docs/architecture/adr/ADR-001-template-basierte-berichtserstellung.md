# ADR-001: Bericht aus Vorlage mit Platzhaltern

**Status:** vorgeschlagen

**Kontext:** Franz will sein Layout behalten, nur die Zahlen sollen sich ändern.

**Entscheidung:** Der alte Bericht wird als HTML-Vorlage mit Platzhaltern gespeichert. Das System füllt nur die Platzhalter.

**Alternativen:** Bericht komplett vom Sprachmodell erzeugen (Layout ändert sich jedes Mal) · .pptx direkt bearbeiten (Format zu komplex).

**Konsequenzen:** Layout bleibt gleich und jede Änderung ist nachvollziehbar. Die Vorlage muss einmal vorbereitet werden.
