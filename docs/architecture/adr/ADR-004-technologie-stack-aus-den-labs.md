# ADR-004: Stack aus den Labs

**Status:** vorgeschlagen

**Kontext:** Wenig Zeit, das Team kennt den Stack aus den Lab-Sessions 1–5.

**Entscheidung:** Streamlit, LangChain, Ollama, ChromaDB, pandas, SQLite, Docker Compose.

**Alternativen:** Eigene Web-App mit React und FastAPI (mehr Aufwand).

**Konsequenzen:** Schneller Start mit vorhandenem Wissen. Die Oberfläche ist mit Streamlit eingeschränkt.
